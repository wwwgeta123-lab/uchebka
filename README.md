# NEXUS — сайт киберспорт-клуба

Киберспорт-клуб NEXUS: игровые залы, турниры, буткемп. Проект сделан из статического
прототипа в `ermolin/computer-club`: теперь это React-приложение с маршрутизацией,
заявками на бронирование и панелью администратора.

## Стек

- **React 18 + Vite** — интерфейс и сборка
- **React Router 6** — маршруты сайта и админки
- CSS из прототипа (`src/styles/style.css`) с реальной палитрой вместо серого макета

## Запуск

```bash
cd client
npm install
npm run dev
```

Сайт откроется на `http://127.0.0.1:5173`.

Сборка:

```bash
npm run build   # результат в client/dist
npm run preview
```

## Страницы

| Маршрут | Назначение |
| --- | --- |
| `/` | Главная: hero, преимущества, залы, железо, игры, акции, отзывы |
| `/catalog` | Список залов с ценами |
| `/catalog/:slug` | Карточка зала: галерея, оборудование, прайс, правила, бронь |
| `/about` | О клубе: цифры, история, команда, фотографии |
| `/contacts` | Контакты, форма бронирования, обратная связь, схема проезда |
| `/admin/login` | Вход в панель администратора |
| `/admin` | Сводка: новые заявки, сообщения, залы |
| `/admin/bookings` | Заявки: фильтр по статусу, подтверждение, отмена, удаление |
| `/admin/messages` | Сообщения из формы обратной связи |
| `/admin/halls` | Управление залами: цены, описания, характеристики |

## Структура

```
client/
  public/images/        иллюстрации и обложки залов
  src/components/       шапка, подвал, карточки, формы
  src/data/site.js      тексты сайта
  src/pages/            страницы сайта
  src/pages/admin/      панель администратора
  src/styles/           reset.css, style.css, extra.css
```

Данные залов и заявки хранятся в базе SQLite и отдаются API на `127.0.0.1:4000`;
в режиме разработки запросы к `/api` проксируются из Vite.
